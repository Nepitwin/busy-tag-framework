## Introduction

The busy-tag-framework is a Python library designed to interact with a busy tag device. It provides a set of APIs to perform various operations such as retrieving file lists, getting firmware versions, and managing storage.

## Features

- Retrieve file and picture lists from the device.
- Get firmware version and local host address.
- Manage storage by retrieving free and total storage sizes.
- Set and get solid colors for LEDs.
- Set the picture to be displayed on the device.
- Adjust display brightness.
